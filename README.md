# Видео в Factorio — by RomOSTiny

Конвертер видео и GIF в автономные зацикленные чертежи Factorio.
Плеер работает без модов; после установки чертежа программа и RCON не нужны.

## Скачать и запустить

Готовая версия для **Windows 10/11 x64** находится в [Releases](https://github.com/RomOSTiny/factorio-video/releases/latest).
Скачайте ZIP, распакуйте всю папку в удобное место и откройте **RomOSTinyVideo.exe**.
Python и FFmpeg отдельно устанавливать не нужно: необходимые компоненты включены.
Не запускайте EXE прямо из ZIP и не отделяйте его от остальных файлов папки.

Проверенная версия игры — **Factorio 2.1.24**, только базовая игра.
Совместимость с 2.0 не заявляется.

## Как пользоваться

1. Нажмите **«Загрузить видео»** и выберите MP4, GIF, MKV, WEBM, MOV или AVI.
2. Выберите разрешение. Программа показывает квадратные размеры для квадратного видео,
   16:9 для горизонтального и 9:16 для вертикального. Поворот телефонных видео учитывается.
3. Выберите FPS. Под ним сразу появится **максимальная длительность** этого режима.
4. Под предпросмотром укажите **«Начало, с»** и **«Конец, с»**. Можно вводить дробные секунды
   с точкой или запятой. Начало — неотрицательное, конец — позже начала и внутри видео.
5. Кнопка **«Смотреть»** запускает предпросмотр выбранного фрагмента; ползунок перематывает его.
6. Нажмите **«Создать чертежи»**, дождитесь завершения, затем **«Скопировать чертежи»**.
7. Выберите **раздельные экран и память** или **всё вместе**, затем **с опорами у экрана**
   или **без опор**. Общая схема сразу копируется. Для раздельного варианта появятся
   две кнопки — по очереди скопируйте и импортируйте экран и память.
8. В Factorio откройте импорт строки чертежа, вставьте строку и постройте схему.
   Подключите электричество: для раздельного варианта — к обоим блокам.

Предпросмотр и схема используют один выбранный фрагмент. Тёмные ролики автоматически
осветляются для ламп; чёрный сохраняется. Коррекция видна в предпросмотре.
Повторяющиеся изображения сжимаются автоматически без дополнительных потерь.
Звук не переносится.

## Размеры и длительность

| Форма | Разрешения |
| --- | --- |
| Квадрат | 16×16, 32×32, 64×64, 96×96, 128×128 |
| 16:9 | 16×9, 32×18, 64×36, 96×54, 128×72 |
| 9:16 | 9×16, 18×32, 36×64, 54×96, 72×128 |

Текущий предел — до **60 секунд** и до **10 000 записей памяти** по консервативной
оценке до сжатия. Поэтому при большом разрешении и FPS фрагмент короче:
например, при 10 FPS 64×64 — до 60 с, 128×72 — до 23,2 с.
Экран 16×16 хорошо подходит для крупных пиксельных рисунков; мелкие детали обычного
видео при таком уменьшении теряются. Предпросмотр помогает подобрать качество.
При замедлении игры ниже 60 UPS замедляется и показ видео.

## Питание и размещение

- **С опорами**: подстанции внутри экрана занимают места отдельных пикселей.
  В 32×32 внутри одна подстанция вместо четырёх ламп; широких разрывов между секциями нет.
- **Без опор**: все пиксели сохранены, питание экрана вы обеспечиваете самостоятельно.
  Возможность запитать центр зависит от размеров и ваших опор. Опоры в памяти остаются.
- Экран и память берите из **одной конвертации**. Каналы радаров назначаются автоматически.
  Удалённый блок памяти можно разместить далеко от экрана на той же силе.
- Лабораторные источники электричества в экспорт не входят.

Для паузы выключите постоянный комбинатор **«ПУСК / ПАУЗА»** слева от экрана;
для продолжения включите его. Для возврата к первому кадру включите **«СБРОС»**,
затем выключите. Значения сигналов оставляйте равными 1.

## Файлы программы

Результаты сохраняются в `output` рядом с EXE; временные файлы — в `tmp`,
автоматические назначения радаров — в `settings`. Папку программы можно разместить
на другом диске. Для каждого результата создаётся отдельный каталог с TXT-строками,
JSON, предпросмотрами и отчётом. Кнопка «Открыть папку результата» ведёт туда.

Разные видео, фрагменты и профили на одной установке получают непересекающиеся
наборы каналов. Идентичный повтор переиспользует назначение. Каталог каналов конечен;
совпадение с чужими чертежами, созданными на другом компьютере, не исключено.

## Проверки версии 0.1.0

Проверены три формы видео, оба способа размещения, варианты питания,
пауза/сброс/зацикливание, восстановление питания и сохранения.
Для демонстрации использованы оригинальные яркие пиксельные анимации;
показ в игре снят непосредственно клиентом Factorio, без осветления готовых кадров.
Это первая публичная версия; окончательные пределы размеров и длительности ещё исследуются.

## Запуск исходного кода

Для разработки нужны Windows, Python 3.13 с Tkinter и `ffmpeg`/`ffprobe` в PATH.
Сторонние Python-пакеты для работы не требуются. Откройте `run.pyw` или выполните:

```powershell
py -3.13 -m videofactorio.gui
```

Для сборки EXE установите зависимости `requirements-build.txt` и запустите `build.py`.
Полученная папка появится в `dist`; `ffmpeg.exe` и `ffprobe.exe` необходимо положить
рядом с EXE вместе с их лицензиями. В готовом ZIP это уже сделано.

Автор: **RomOSTiny**. Компоненты FFmpeg, Python, Tcl/Tk сохраняют собственные лицензии;
они находятся в папке `third_party` готовой сборки.
